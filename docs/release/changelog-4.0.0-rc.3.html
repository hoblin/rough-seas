⚠️ Release candidate 3. For testers: the full 4.0 release comes this weekend. Use a test world; a world started on an RC may not carry over to 4.0.

What changed since rc.2:

  • Paddling and poling on a server. The paddle and the pole no longer stall after changing sides, and the server no longer logs an error on every stroke.
  • The dugout no longer fails to draw once its rim is clayed, and every vanilla wood has its own toughness.
  • Poles stack to 32, and a split drops them in full stacks.
  • Poles and laths lie on the ground in a pile as long as they are, like any other item.
  • A dropped lath is one lath.
  • Poles and laths burn as long as the firewood of the logs they came from.

Bug reports: the comments here or GitHub issues.

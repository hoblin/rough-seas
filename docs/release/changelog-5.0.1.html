A fix for swimming beside other mods.

  • You swim again beside Player Model Library. A mod that changes the game's own swim stroke, Player Model Library 1.25.0 among them, could leave a swimmer hanging in the water, unable to move or come up. Our swimming no longer depends on what other mods do to that stroke.
  • Player Model Library's swim speed counts. A character its body, class or trait makes a better swimmer pulls that much harder with the arms; a worse one, that much weaker.

Thanks to TheFayBank for the report and the save. Player Model Library 1.25.0 is now on the list of tested mods: Beside other mods.

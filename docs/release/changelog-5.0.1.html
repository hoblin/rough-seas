A fix for swimming beside other mods.

  • You swim again beside Player Model Library. With Realistic swimming on, a mod that hooks the game's own swim stroke, Player Model Library 1.25.0 among them, could leave a swimmer hanging in the water, unable to move or come up. Another mod's hook on that stroke no longer stops our swimmer. If you switched realistic swimming off to get around it, you can switch it back on.
  • Player Model Library's swim speed counts. A character whose body, class or trait makes them a better swimmer pulls that much harder with the arms; a worse one, that much weaker.
  • Extreme Weathers, Shipwright and Walkable Entities on newer versions. Rough Seas worked with each only on the version we tested and left any other alone. It now works with any version that still has what it reaches, and logs a warning naming what is missing when something is gone. On a Shipwright other than 1.5.1, its boats now ride our sea and can crack, flood and sink.

Thanks to TheFayBank for the report and the save. Player Model Library 1.25.0 is now on the list of tested mods: Beside other mods.
